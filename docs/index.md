# neo-oscal

Persönliches Werkzeug zur Controls-Automatisierung nach
[NIST OSCAL](https://pages.nist.gov/OSCAL/), inspiriert von
[myctrl.tools](https://myctrl.tools/).

Kataloge (z. B. NIST SP 800-53 Rev5) durchsuchen, Profile und Baselines bilden,
die Umsetzung dokumentieren und als OSCAL exportieren.

- **Backend:** FastAPI + Pydantic
- **Frontend:** Vite + React + TypeScript
