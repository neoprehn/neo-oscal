# Roadmap

Entlang der OSCAL-Schichten:

1. **Catalog** – Kataloge laden, durchsuchen, anzeigen (Gerüst steht)
2. **Profile** – Baselines (Low/Moderate/High) auflösen, eigene Profile mit Parametern
3. **Component Definition** – Komponenten mit Control-Umsetzung
4. **SSP** – System Security Plan
5. **Assessment Plan/Results, POA&M**
6. Crosswalk zwischen Frameworks, OSCAL-Export (JSON/YAML/XML)

Querschnitt: CI/CD und Betrieb auf oscal.neoprehn.de (Pipeline steht, siehe
[Betrieb & CI/CD](betrieb.md)).
