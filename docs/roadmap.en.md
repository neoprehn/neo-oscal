# Roadmap

Following the OSCAL layers:

1. **Catalog** – load, search and display catalogs (scaffold in place)
2. **Profile** – resolve baselines (Low/Moderate/High), custom profiles with parameters
3. **Component Definition** – components with control implementations
4. **SSP** – System Security Plan
5. **Assessment Plan/Results, POA&M**
6. Crosswalk between frameworks, OSCAL export (JSON/YAML/XML)

Cross-cutting: CI/CD and operations on oscal.neoprehn.de (pipeline in place, see
[Operations & CI/CD](betrieb.md)).
